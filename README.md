# 授業出欠管理アプリ (Attendance Tracker)

大学生向けのシンプルで高機能な授業・出欠管理アプリケーションです。
React + Viteで構築されており、クォーター（学期）制への対応や、ローカルストレージを用いた記録の保存機能を備えています。

> **特徴**: 電波の悪い場所でもすぐ開けてすぐ確認できます - インターネット接続不要で、ブラウザのみで動作します！

## 📋 主な機能

- **⚡ 時間割＆ワンタップ打刻**: 今日の授業だけが自動で表示され、「出席」「遅刻」「欠席」「休講」をワンタップで記録できます。
- **🗓️ 過去の日付にも記録**: 前週・次週の移動や日付の指定で、記録し忘れた日にもあとから記録できます（未来の日付は記録不可）。
- **✏️ 記録の修正・削除**: 間違えて付けた記録は、あとから状態の変更や削除ができます。
- **📝 授業ごとのメモ機能**: 持ち物や課題の期限などを授業ごとにメモ可能。「その日だけのメモ」（教室変更など）も付けられます。
- **🔔 授業中・次の授業の強調**: 今日の画面では、いま行われている授業と次の授業にバッジと枠線が付きます。
- **🌙 ダークモード**: 設定タブで自動（OSに従う）／ライト／ダークを切り替えられます。
- **➕ 授業・キャンパス情報をアプリ上で編集**: 日別画面の「＋ 授業を追加」や週間表の空きマス「＋」から授業を追加でき、授業詳細から編集・削除もできます。設定タブでは建物・施設情報の編集とマップ画像のアップロードも可能です。
- **⚠️ 危険タブ**: 出席記録の全削除など取り消せない操作は、設定とは別の「危険」タブに分けています。実行には確認の文字入力が必要で、削除前にバックアップも書き出せます。
- **💾 バックアップ**: 設定タブから、授業・設定・記録・メモなどを JSON で書き出し／読み込みできます。
- **⚙️ 設定タブ**: クォーター期間・時限の時間・授業の表示/非表示を画面から変更でき、出席記録の全削除もできます（`constants.js` の値が初期値になります）。
- **📅 自動クォーター判定**: 設定したクォーター期間から第1Q〜第4Qを自動で判定し、期間外の誤打刻を防ぎます。
- **🚀 動作の軽量化・高速化**: `useMemo` と `useCallback` を活用し、文字入力時やタブ切り替え時の無駄な再計算を抑え、スマホでもサクサク動きます。
- **🚫 本日の授業なし表示**: 授業がない日は「本日の授業なし」と表示され、見やすさが向上しています。
- **📂 履歴のアコーディオン表示**: 「月 ＞ 週 ＞ 日付」の階層でスッキリと履歴を振り返ることができます。
- **📊 出欠・遅刻機能**: 授業ごとの出席率や、全体の出席率を視覚的にグラフ化します。
- **🗺️ キャンパスマップ**: 迷いやすいキャンパス内の教室や施設情報を素早く確認できます。
- **💾 オフライン対応**: LocalStorageを使用してすべてのデータをローカルに保存。インターネット不要です。

## ⚙️ 自分の時間割を登録する方法（カスタマイズ）
このアプリは、使う人それぞれの時間割に合わせて簡単にカスタマイズできます。

### 画面から設定する（おすすめ）
アプリの画面上で、コードを触らずに設定できます。
- **授業の追加・編集・削除**: 日別画面の「＋ 授業を追加」、週間表の空きマスの「＋」、設定タブの「＋ 授業を追加」から追加できます。編集・削除は授業詳細の「授業情報を編集」または設定タブの「編集」から行います。
- **クォーター期間・時限の時間**: 設定タブで変更できます。
- **キャンパス・建物情報・マップ画像**: 設定タブで追加・編集・アップロードできます。
- **バックアップ**: 設定タブで JSON として書き出し・読み込みできます。機種変更やブラウザのデータ消去の前に書き出しておくと安心です。

画面で行った変更はブラウザの LocalStorage に保存され、`src/data/constants.js` の値より優先されます。

### constants.js で初期データを設定する
`src/data/constants.js` は、最初に表示される初期データです（画面で一度編集した項目は画面側の内容が使われます）。
複数の端末で同じ初期データを使いたい場合や、配布用に設定したい場合は、以下の要領で編集してください。

### 1. 授業の追加 (MY_COURSES)
src/data/constants.js を開き、MY_COURSES の配列に自分の授業を追加してください。
```javascript
export const MY_COURSES = [
  { 
    id: "unique-id-1",       // 重複しない任意のID (例: "mon-1")
    name: "プログラミング基礎", // 授業名
    quarter: 1,              // クォーター (1, 2, 3, 4) 
                             // ※通年や前学期通しの場合は [1, 2] のように配列にします
    dayOfWeek: 1,            // 曜日 (1:月, 2:火, 3:水, 4:木, 5:金, 6:土, 0:日)
    period: 1,               // 時限 (1限目なら 1)
    campus: "north",         // キャンパスID (CAMPUSES の id)
    room: "3-601",          // 教室番号
    teacher: "山田 太郎"        // 担当教員
  },
  // ... 自分の授業をどんどん追加！
];
```

### 2. 時限の時間設定 (PERIODS)
大学のチャイムに合わせて授業時間を変更できます。
```javascript
export const PERIODS = {
  1: { start: '09:00', end: '10:30' },
  2: { start: '10:40', end: '12:10' },
  // ... 大学の時間割に合わせて変更してください
};
```

### 3. クォーターの期間 (QUARTERS)
初期値は仮の日付です。**大学の学年暦に合わせて必ず変更してください。**
期間外の日付は「期間外」となり記録できません。
```javascript
export const QUARTERS = {
  1: { start: '04-01', end: '05-31' }, // 'MM-DD' 形式
  2: { start: '06-01', end: '07-31' },
  3: { start: '09-01', end: '10-31' },
  4: { start: '11-01', end: '01-31' }, // 年をまたぐ場合は start を end より後にする
};
```

### 4. マップと施設情報 (CAMPUSES / CAMPUS_BUILDINGS)
所属する大学のキャンパス情報に変更できます。
```javascript
export const CAMPUSES = [
  { id: "north", name: "北キャンパス", mapImage: "/north_campus_map.jpg" }, // 画像がなければ null
  // ... 複数のキャンパスに対応
];

export const CAMPUS_BUILDINGS = {
  north: [ // キーは CAMPUSES の id
    { id: "n-3", name: "3号館", description: "講義室・PC教室" },
    // ... 建物情報を追加
  ],
};
```
📌 マップ画像を使用する場合: public/ ディレクトリにマップ画像（.jpg や .png）を配置し、CAMPUSES の mapImage にパスを指定してください。設定タブからアップロードした画像がある場合は、そちらが優先されます。画像がない場合は「マップ画像がありません」と表示されます。

## 🎯 使用シーン
- 講義中: 出席・遅刻・欠席・休講をワンタップで記録
- 講義前: 今日のスケジュール確認、教室位置確認、持ち物や課題のメモ確認
- 学期末: 授業ごとの出席率を分析、欠席パターン確認
- キャンパス内: 教室や施設の位置をすぐ確認

## 💡 Tips
- 一度設定すれば、あとはアプリを開いて出席状況を記録するだけ
- すべてのデータはブラウザに保存されるため、バックアップを取りたい場合はブラウザの開発者ツールで LocalStorage をエクスポート可能
- オフラインで完全に動作するため、どんな環境でもすぐに確認できます
- スマホからの起動時は、Termuxウィジェットから node ./node_modules/vite/bin/vite.js で直接Viteを起動することで高速化が可能です
