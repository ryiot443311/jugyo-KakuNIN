# 授業出欠管理アプリ (Attendance Tracker)

大学生向けのシンプルで高機能な授業・出欠管理アプリケーションです。
React + Viteで構築されており、クォーター（学期）制への対応や、ローカルストレージを用いた記録の保存機能を備えています。

> **特徴**: 電波の悪い場所でもすぐ開けてすぐ確認できます - インターネット接続不要で、ブラウザのみで動作します！

## 📋 主な機能

### ✅ 記録する
- **ワンタップで打刻**: 今日の授業だけが表示され、「出席」「遅刻」「欠席」「休講」をワンタップで記録できます。記録直後の数秒間は画面上部に「元に戻す」が出ます（左右スワイプで消せます）。
- **過去の日にも記録**: 前週・次週への移動や左右スワイプで日を移り、記録し忘れた日にもあとから記録できます（未来の日・クォーター期間外の日は記録できません）。
- **記録の修正・削除**: 付けた記録は、あとから状態の変更や削除ができます。
- **記録し忘れのお知らせ**: 直近4週間で、終わったのに記録していない授業があると、日別画面に件数を表示します。一覧から選ぶと、その日に移動できます。
- **授業中・次の授業の強調**: いま行われている授業と次の授業に、バッジと枠線が付きます。
- **連続欠席の注意**: 同じ授業を2回以上続けて欠席していると、授業カードに注意を表示します（休講は数えません）。

### 🗓️ 時間割・学年暦
- **授業の登録・編集**: 日別画面・週間表の空きマス・設定タブから授業を追加でき、授業詳細から編集・削除できます。
- **クォーター制**: 設定したクォーター期間から第1Q〜第4Qを自動で判定します。通年・複数クォーターの授業にも対応しています。
- **隔週授業**: 授業ごとに「毎週／奇数週／偶数週」を選べます。クォーターが始まる週を第1週（月曜始まり）として数えます。
- **休校日・曜日振替・補講**: 設定タブの「休校日・振替・補講」で登録します。
  - 休校日（1日または期間）は、時間割の授業を出さず、記録し忘れ・通知・カレンダー書き出しの対象から外します。
  - 曜日振替（例: 「この日は月曜日の授業」）の日は、振替先の曜日の授業を表示します。
  - 補講は、登録済みの授業を指定した日・時限（教室も変更可）に1回だけ追加します。記録はその授業の出席率に入ります。
- **新年度の準備**: 設定タブの「新年度の準備」で、バックアップ → 続ける授業の選択（ほかは非表示。記録と履歴は残ります） → 前の年度の休校日・振替・補講の削除 → クォーター期間の見直し、の順に進められます。

### 📚 メモ・課題・通知
- **メモ**: 授業ごとのメモ（持ち物など）と、「その日だけのメモ」（教室変更など）を付けられます。
- **課題・期限**: 授業詳細で課題（名前・期限）を登録し、完了にできます。期限が7日以内の課題と期限切れの課題は、日別画面の上部に表示します。
- **通知**: 「授業開始の10分前」「授業が終わったとき未記録なら」の通知をオンにできます（アプリを開いている間）。
- **カレンダーに書き出す**: 時間割をクォーター期間の繰り返し予定（.ics、アラーム付き）として書き出せます。休校日・振替・補講も反映します。アプリを閉じていても、カレンダーから通知が届きます。

### 📊 振り返る
- **分析**: 授業ごと・全体の出席率、出席率の基準（%）を下回る科目の警告と「あと何回欠席できるか」、週ごとの出席率の推移、欠席の多い曜日・時限を表示します。グラフの値は表でも確認できます。前の年度を選ぶと、非表示にした授業の記録も含めて表示します。
- **履歴**: 「年度 ＞ 月 ＞ 週 ＞ 日付」の階層で振り返れます。古い年度は折りたたんで表示します。
- **CSV出力**: 年度・クォーターで絞り込み、記録の明細と授業ごとの集計を CSV で書き出せます（Excel 対応）。

### 🗺️ キャンパスマップ
- 教室や施設の情報とマップ画像をすぐ確認できます。設定タブで建物・施設情報の編集とマップ画像のアップロードができます。

### 💾 データと動作
- **端末に保存・オフライン対応**: データはブラウザ（LocalStorage、マップ画像は IndexedDB）に保存します。本番ビルドでは一度開くと、通信できなくても起動できます。
- **バックアップ**: 授業・設定・記録・メモ・課題・学年暦などを JSON で書き出し／読み込みできます。読み込みは、手元にないものだけを足す「統合」（2台の端末で使うとき）と、丸ごと入れ替える「置き換え」を選べます。以前のバージョンのデータもそのまま引き継げます。
- **危険な操作の保護**: 出席記録の全削除などは、設定タブ最下部の「危険な項目」にまとめ、確認の文字入力を必要にしています。
- **アプリとして使う**: ホーム画面に追加でき、アイコンの長押しで「今日の授業」「週間の時間割」「出席の分析」を直接開けます。
- **見た目**: 手帳風のデザインで、自動（OSに従う）／ライト／ダークを切り替えられます。記録済みの見せ方は「印（ハンコ）」と「記号（○△×）」から選べます。
- **軽さ**: 漢字フォントはよく使う順に分けたファイルにしており、画面に出ている文字を含むファイルだけを読み込みます。
- **アクセシビリティ**: 文字のコントラストは WCAG AA 以上です。ダイアログはキーボード（Tab・Esc）で操作でき、スワイプ操作にはボタンの代わりがあります。

## ⚙️ 自分の時間割を登録する方法（カスタマイズ）
このアプリは、使う人それぞれの時間割に合わせて簡単にカスタマイズできます。

### 画面から設定する（おすすめ）
アプリの画面上で、コードを触らずに設定できます。
- **授業の追加・編集・削除**: 日別画面の「＋ 授業を追加」、週間表の空きマスの「＋」、設定タブの「＋ 授業を追加」から追加できます。編集・削除は授業詳細の「授業情報を編集」または設定タブの「編集」から行います。
- **クォーター期間・時限の時間**: 設定タブで変更できます。
- **キャンパス・建物情報・マップ画像**: 設定タブで追加・編集・アップロードできます。
- **バックアップ**: 設定タブで JSON として書き出し・読み込みできます。機種変更やブラウザのデータ消去の前に書き出しておくと安心です。

画面で行った変更はブラウザの LocalStorage（マップ画像は IndexedDB）に保存され、`src/data/` の初期データより優先されます。

### 実データを公開せずに管理する（constants.local.js）
このリポジトリには、架空のサンプルデータ（`src/data/constants.sample.js`）だけが入っています。
自分の実際の時間割・教室・キャンパス情報は、次の手順で**コミットされないファイル**に置きます。
```bash
cp src/data/constants.sample.js src/data/constants.local.js
```
`src/data/constants.local.js` を自分のデータに書き換えてください。`.gitignore` 済みなので、`git add` しても公開されません。
書いた項目（`MY_COURSES`・`PERIODS`・`QUARTERS`・`CAMPUSES`・`CAMPUS_BUILDINGS`）だけがサンプルより優先され、書かなかった項目はサンプルが使われます。
マップ画像などの実データは `public/local/` に置くと同様に除外されます（`mapImage: '/local/xxx.jpg'` のように指定）。

### 初期データの書き方
以下は `constants.local.js`（または `constants.sample.js`）に書く内容です。画面で一度編集した項目は画面側の内容が使われます。

### 1. 授業の追加 (MY_COURSES)
MY_COURSES の配列に自分の授業を追加してください。
```javascript
export const MY_COURSES = [
  { 
    id: "unique-id-1",       // 重複しない任意のID (例: "mon-1")
    name: "プログラミング基礎", // 授業名
    quarter: 1,              // クォーター (1, 2, 3, 4) 
                             // ※通年や前学期通しの場合は [1, 2] のように配列にします
    dayOfWeek: 1,            // 曜日 (1:月, 2:火, 3:水, 4:木, 5:金, 6:土, 0:日)
    period: 1,               // 時限 (1限目なら 1)
    campus: "north",         // キャンパスID (CAMPUSES の id)
    room: "3-601",          // 教室番号
    teacher: "山田 太郎"        // 担当教員
  },
  // ... 自分の授業をどんどん追加！
];
```

### 2. 時限の時間設定 (PERIODS)
大学のチャイムに合わせて授業時間を変更できます。
```javascript
export const PERIODS = {
  1: { start: '09:00', end: '10:30' },
  2: { start: '10:40', end: '12:10' },
  // ... 大学の時間割に合わせて変更してください
};
```

### 3. クォーターの期間 (QUARTERS)
初期値は仮の日付です。**大学の学年暦に合わせて必ず変更してください。**
期間外の日付は「期間外」となり記録できません。
```javascript
export const QUARTERS = {
  1: { start: '04-01', end: '05-31' }, // 'MM-DD' 形式
  2: { start: '06-01', end: '07-31' },
  3: { start: '09-01', end: '10-31' },
  4: { start: '11-01', end: '01-31' }, // 年をまたぐ場合は start を end より後にする
};
```

### 4. マップと施設情報 (CAMPUSES / CAMPUS_BUILDINGS)
所属する大学のキャンパス情報に変更できます。
```javascript
export const CAMPUSES = [
  { id: "north", name: "北キャンパス", mapImage: "/north_campus_map.jpg" }, // 画像がなければ null
  // ... 複数のキャンパスに対応
];

export const CAMPUS_BUILDINGS = {
  north: [ // キーは CAMPUSES の id
    { id: "n-3", name: "3号館", description: "講義室・PC教室" },
    // ... 建物情報を追加
  ],
};
```
📌 マップ画像を使用する場合: public/ ディレクトリにマップ画像（.jpg や .png）を配置し、CAMPUSES の mapImage にパスを指定してください。設定タブからアップロードした画像がある場合は、そちらが優先されます。画像がない場合は「マップ画像がありません」と表示されます。

## 🔒 セキュリティ
- **開発サーバー・プレビューは、既定では自分の端末からだけ開けます。** ビルドしたファイルには `constants.local.js` の実データ（時間割など）が含まれるため、同じ Wi-Fi の他の人から見られないようにしています。スマホなど別の端末から開きたいときだけ、`EXPOSE_LAN=1 npm run dev` のように指定してください（信頼できるネットワークでのみ）。
- 本番ビルドのページには、自分のファイルと `data:` 画像以外を読み込ませない Content-Security-Policy を付けています。
- バックアップ・保存データは読み込み時に検証し、不正な値は捨てます。マップ画像の指定も、アプリ内のパスか `data:image` に限っています。
- CSV出力は、`=` などで始まる値が表計算ソフトで式として実行されないよう処理しています。
- 依存パッケージは `npm audit` で確認しています（既知の脆弱性 0 件）。

## 🔤 フォントの作り直し（開発者向け）
漢字フォントは `scripts/split-font.py` で、画面の文字（`src` 内の文字列）を入れた `00` と、よく使う順に分けた `01` 以降のファイルに分けています。
画面の文言を変えても表示は崩れません（新しい漢字は `01` 以降のどれかに入っています）。読み込むファイルを最小にしたいときだけ、作り直してください。
```bash
pip install fonttools brotli wordfreq
python scripts/split-font.py   # src/assets/fonts/techo-mincho-kanji-NN.woff2 と kanji.css を作り直す
```
